# 강의 예습 노트

수업 전에 강의 PDF를 올리면 **핵심 내용 요약**과 **주요 개념 5개**를 한 장으로 정리해 주는 웹 앱입니다.

## 기능
- PDF 업로드 (끌어다 놓기 / 파일 선택)
- 브라우저에서 PDF 텍스트 추출 ([pdf.js](https://mozilla.github.io/pdf.js/))
- 핵심 내용 요약 (쪽 번호 포함), 주요 개념 5개 (한국어·영어 용어·설명)
- 결과를 텍스트로 복사

## 참고
- 요약 기능은 claude.ai 아티팩트의 `sample` 기능(Claude 호출)을 사용합니다. 이 저장소의 `index.html`을 일반 브라우저나 GitHub Pages에서 열면 화면과 예시는 보이지만, 요약 버튼은 "Claude 정리 기능을 쓸 수 없어요" 안내가 뜹니다.
- 이미지로만 된(스캔) PDF는 글자를 추출할 수 없습니다.
